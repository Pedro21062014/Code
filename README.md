## ✨ About CodeGem

**CodeGem** is an experimental AI-powered coding environment designed to bring AI assistance, code editing, project exploration, and browser-based development into a single workspace.

The project was built as an exploration of what a modern AI coding studio could look like in the browser, combining a polished interface with tools for working with code and AI models.

> **Important:** CodeGem is an independent project and is not affiliated with or endorsed by Google, OpenAI, NVIDIA, or any other AI provider whose models or services may be supported by the application.

## 💎 Why is this repository open source?

CodeGem started as a personal project and was developed as an experiment to build a complete AI coding application.

At some point, I realized that I wasn't going to finish the application to the level I originally planned. Instead of leaving the code private or abandoning it completely, I decided to **open-source the project**.

This repository is now available for developers who want to:

- Explore how the project was built
- Reuse parts of the implementation
- Learn from the architecture and UI
- Experiment with AI-powered development tools
- Fork the project and continue development
- Build something new on top of the existing codebase

**The project may be unfinished, but the code can still be useful.**

## 📦 Getting Started

### Prerequisites

Make sure you have:

- [Node.js](https://nodejs.org/) installed
- npm installed
- The required API keys and environment variables configured

### Installation

Clone the repository:

```bash
git clone https://github.com/Pedro21062014/Code.git
cd Code
```

Install dependencies:

```bash
npm install
```

Create your local environment file:

```bash
cp .env.example .env.local
```

> If the repository does not contain an `.env.example`, create `.env.local` manually and configure the environment variables required by the services you intend to use.

Start the development server:

```bash
npm run dev
```

The application will be available at the local URL displayed by Vite.

---

## 🏗️ Production Build

Create a production build with:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

For Cloudflare Pages deployment:

```bash
npm run deploy
```
